Fonts bundled for the Theomyth UI (all SIL Open Font License 1.1, from github.com/google/fonts):
- Cinzel Decorative (Bold 700, Black 900) - logo only
- Lilita One - headings, buttons, names
- Nunito (variable, wght axis) - body and labels

None of them cover Greek letters; Greek text falls back to the system font (see status.md).
